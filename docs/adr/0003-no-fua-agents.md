# ADR 0003 — Sin agentes ni marca FUA

## Contexto

La plataforma de Fundación incluye IA, RAG y look Nexus Glass.

## Decisión

Este repo no incluye `apps/agents`, Foundry, chat ni loaders multi-fuente. Identidad visual y nombres de negocio son propios (editorial / consultoría).

## Consecuencias

Cualquier extracción de código de Fundación debe revisarse contra la matriz A/B/C antes de pegar.
